Keybinds

Tunings

Info

Changes applied on initialization of a board, so exit from a card and go back.

To modify anki's shortcuts use Customize Keyboard Shortcuts addon.

Common conflicts:

  • Space is anki's shortcut for See Answer and marking card Good
  • Ctrl+KeyZ is anki's undo
  • KeyD is anki's shortcut to Decks tab
  • KeyR is anki's replay audio
  • KeyA is anki's add card
